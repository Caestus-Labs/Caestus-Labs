# Caestus Labs

A minimal, text-only company website at https://caestuslabs.com.

The homepage contains the company name, "Simulating Reality", and a contact link to andrew@jiang.now. Its HTML and CSS are self-contained in `index.html`; it needs no JavaScript, external fonts, or build step.

## Local preview

Open `index.html` in a browser, or serve the repository root with a static file server.

## Deployment

GitHub Pages publishes the root of `main`. The custom domain is set in `CNAME`.

Commit website changes directly to `main`. The `caestuslabs-com/` Next.js project and `archive/` contain earlier versions and are not the current homepage. The legacy Next.js workflow is separate from the active GitHub Pages branch deployment.
